# Система автоматизации утверждения расходов

## О проекте

Этот проект — тестовое задание на разработку системы для автоматизации процесса подачи, рассмотрения и утверждения заявок на расходы в компании с несколькими офисами.

Система предназначена для двух ролей:
* **Менеджер-финансист**: создает и отслеживает свои заявки.
* **Руководитель**: рассматривает и утверждает или отклоняет все заявки.
