# Схема Базы Данных

Здесь описана структура таблиц для хранения данных системы утверждения расходов. Мы используем реляционную модель.

## Таблица 1: `users` - Пользователи

Хранит информацию о пользователях системы (менеджерах и руководителях).

| Имя поля     | Тип данных         | Описание                                    |
|--------------|--------------------|---------------------------------------------|
| `id`         | `INTEGER PRIMARY KEY` | Уникальный идентификатор пользователя (PK) |
| `full_name`  | `VARCHAR(255)`     | Полное имя пользователя (ФИО)               |
| `email`      | `VARCHAR(255) UNIQUE` | Электронная почта для входа и уведомлений  |
| `role`       | `VARCHAR(50)`      | Роль в системе: 'manager' или 'director'    |
| `office_id`  | `INTEGER`          | ID офиса, к которому привязан (FK)          |
| `created_at` | `TIMESTAMP`        | Дата и время создания записи                |

* **Связи**: `office_id` ссылается на `offices.id`.

## Таблица 2: `offices` - Офисы

Справочник офисов компании.

| Имя поля   | Тип данных         | Описание                                 |
|------------|--------------------|------------------------------------------|
| `id`       | `INTEGER PRIMARY KEY` | Уникальный идентификатор офиса (PK)   |
| `city`     | `VARCHAR(255)`     | Город расположения                       |
| `country`  | `VARCHAR(255)`     | Страна расположения                      |
| `currency` | `VARCHAR(10)`      | Код валюты по умолчанию для офиса (USD, RUB) |

## Таблица 3: `expense_categories` - Категории расходов

Справочник статей (категорий) расходов.

| Имя поля       | Тип данных         | Описание                                    |
|----------------|--------------------|---------------------------------------------|
| `id`           | `INTEGER PRIMARY KEY` | Уникальный идентификатор категории (PK) |
| `name`         | `VARCHAR(255)`     | Название категории (Командировка, Ремонт)   |

## Таблица 4: `expense_requests` - Заявки на расходы

Основная таблица, хранящая все заявки на расходы.

| Имя поля          | Тип данных         | Описание                                                         |
|-------------------|--------------------|------------------------------------------------------------------|
| `id`              | `INTEGER PRIMARY KEY` | Уникальный идентификатор заявки (PK)                             |
| `amount`          | `DECIMAL(10, 2)`   | Сумма расхода                                                    |
| `currency`        | `VARCHAR(10)`      | Валюта расхода (на момент создания заявки)                         |
| `status`          | `VARCHAR(50)`      | Текущий статус: 'draft', 'pending', 'approved', 'rejected'       |
| `comment`         | `TEXT`             | Комментарий от менеджера                                         |
| `rejection_reason`| `TEXT`             | Причина отклонения (заполняется руководителем)                   |
| `user_id`         | `INTEGER`          | ID автора заявки (FK к `users.id`)                               |
| `category_id`     | `INTEGER`          | ID категории расхода (FK к `expense_categories.id`)              |
| `reviewer_id`     | `INTEGER`          | ID руководителя, рассмотревшего заявку (FK к `users.id`)         |
| `created_at`      | `TIMESTAMP`        | Дата и время создания                                            |
| `updated_at`      | `TIMESTAMP`        | Дата и время последнего обновления                               |

## Таблица 5: `attachments` - Вложения

Хранит информацию о прикрепленных к заявкам файлах.

| Имя поля         | Тип данных         | Описание                                                    |
|------------------|--------------------|-------------------------------------------------------------|
| `id`             | `INTEGER PRIMARY KEY` | Уникальный идентификатор файла (PK)                         |
| `request_id`     | `INTEGER`          | ID заявки, к которой прикреплен файл (FK)                   |
| `file_name`      | `VARCHAR(255)`     | Оригинальное имя файла                                      |
| `file_path`      | `VARCHAR(255)`     | Путь к файлу на сервере или в облачном хранилище            |
| `uploaded_at`    | `TIMESTAMP`        | Дата и время загрузки                                       |

* **Связи**: `request_id` ссылается на `expense_requests.id`.
